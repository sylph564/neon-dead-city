# NEON: DEAD CITY — update 0.3.0


## 0.3.0 — combat, traffic and cyberware overhaul

- Rebuilt the cyberware terminal into a dark burgundy multi-column layout with implant catalogue, operator preview and vertical yellow capacity meter.
- Added distinct first-person attack wind-up, slash/whip/uppercut and recovery animations for Mantis Blades, Monowire and Gorilla Arms.
- Added impact feedback, hit sparks and per-implant melee reach/damage profiles.
- Added animated rainbow weapon trails during Sandevistan and Monowire attacks.
- Converted pedestrians to CharacterBody3D actors with real hitboxes, health, damage response, knockback and defeat state.
- Added collision bodies to large district buildings and obstacle checks for traffic.
- Added neon signage and stronger atmospheric lighting/fog while keeping the Compatibility renderer for mobile devices.

Runtime verification in Godot is still required before calling this release stable.
