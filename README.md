# NEON: DEAD CITY

A first-person 3D cyberpunk city prototype built with Godot 4.

## Current prototype
- Procedurally arranged city blocks with neon window lighting.
- First-person movement and mouse look.
- Mobile touch controls: left side to move, right side to look.
- Android arm64 debug export preset.

## Build an Android APK
The **Build Android APK** workflow runs on pushes to `main` and can also be started manually from the Actions tab. When it succeeds, open the run and download the `NEON-DEAD-CITY-Android` artifact.

This is an early playable foundation, not a finished open-world game. Vehicles, quests, combat, NPCs, implants, save data, and detailed interiors are future features.
